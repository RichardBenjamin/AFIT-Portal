# AFIT Portal Security Enhancement

## Project Overview

The **AFIT Portal Security Enhancement** project aims to fortify the security of the Air Force Institute of Technology (AFIT) student portal against cyberattacks. The focus is on enhancing access control through the implementation of **Two-Factor Authentication (2FA)** and a **Password Strength Meter**. This initiative addresses the vulnerabilities of the current **single-factor authentication (SFA)** system, which exposes sensitive student data to potential breaches.

---

## Research Background

Educational institutions have increasingly become primary targets for cyberattacks, resulting in significant privacy, financial, and reputational risks. The existing portal’s reliance on **single-factor authentication** leaves it vulnerable to unauthorized access and data breaches. This research proposes a comprehensive security system that mitigates these risks through:

- **Integration of Two-Factor Authentication (2FA)**
- **Implementation of a Password Strength Meter**
- Enhanced **password complexity enforcement**
- Secure and user-friendly **password reset mechanism**
- Flexible login options to reduce dependency on institutional staff for account management

---

## Development Methodology

The project utilizes an **agile development methodology**, allowing for iterative feedback and continuous improvement. The implementation adopts modern web technologies for both the **frontend** and **backend**, ensuring a scalable and reliable portal solution.

---

## Key Features

- **Two-Factor Authentication (2FA):** Adds a second layer of security via email-based OTP verification.
- **Password Strength Meter:** Provides real-time feedback on password strength, encouraging users to create stronger passwords.
- **Secure Password Reset:** Offers a streamlined mechanism for users to recover their accounts securely.
- **Flexible Login Options:** Reduces reliance on institutional support for account management.

---

## Findings

The findings from this research indicate that integrating **multi-factor authentication (MFA)** with a **password strength meter** significantly enhances the security posture of the AFIT portal against brute-force attacks and fosters improved user engagement with stronger password practices.

---

## Objectives

This study not only aims to strengthen **AFIT’s cybersecurity defenses** but also serves as a model for similar educational institutions striving to improve their access control systems in response to growing cyber threats.
